# T2.4 · Archivo: listado, búsqueda, CSV, correcciones y borrado

**Fase:** 2 · **Quién:** 🤖 Sonnet · **Depende de:** T2.3 · **Tamaño:** M
**Rama:** `t2-4-archivo-api`

## Objetivo

Endpoints que usa la pestaña Archivo.

## Contexto (leer)

- `docs/especificacion.md` §4.2 (Archivo), §10 (columnas de búsqueda, índices, regla de lectura, `audit_log`), §11 (`GET /companies/:id/scans`, `.csv`, `PATCH` y `DELETE /scans/:id`).

## Qué hacer

1. `GET /companies/:id/scans` (miembro):
   - Filtros: `q` (texto: cliente, número, RUT, sello, local), `type` (`factura` = factura_emitida + nota_credito_emitida, `devolucion`, `otro` = otro + no_reconocido), `conformidad` (uno o varios), `revisar=true`, `from`, `to` (fechas de captura, inclusive, en hora de Uruguay `America/Montevideo`).
   - Excluir `deleted_at` no nulo.
   - Orden `captured_at desc, id desc`; paginación por cursor opaco (base64 de `captured_at|id`), `limit` por defecto 30, máximo 100. Respuesta `{ items: ScanDto[], next_cursor }`.
   - La búsqueda considera también los valores corregidos: si hay corrección de una columna de búsqueda, al guardar la corrección se actualiza la columna (ver punto 3), así el filtro funciona sobre lo que se muestra.
2. `GET /companies/:id/scans.csv` (miembro): mismos filtros, sin paginar (tope 10.000 filas, streaming). Columnas: fecha de captura, tipo, serie, número, fecha del documento, cliente RUT, cliente, local, total, conformidad, a revisar (sí/no), revisado (sí/no), escaneado por, y una columna por cada campo opcional que aparezca en al menos una fila. Valores efectivos (corrección si existe). UTF-8 con BOM, separador `;` (Excel en español) y decimales con coma; documentar la elección. `Content-Disposition: attachment; filename="comprobantes-AAAA-MM-DD.csv"`.
3. `PATCH /scans/:id` (miembro): `{ corrections?: { clave: valor|null }, reviewed?: boolean }`.
   - Validar que las claves estén en `fields_requested` o sean del QR.
   - Hacer merge en `corrections` (null borra la corrección); nunca tocar `extracted`.
   - Actualizar las columnas de búsqueda con el valor efectivo.
   - `reviewed=true` → `reviewed_by`, `reviewed_at`; `false` los limpia.
   - `audit_log` con valor anterior y nuevo.
4. `DELETE /scans/:id` (admin): borrado lógico (`deleted_at`), `audit_log`. Sigue contando para el uso si era facturable.

## Criterios de aceptación (tests)

- Filtros combinados y paginación sin duplicados ni saltos (crear 75 escaneos de prueba).
- Corregir `cliente_nombre` cambia lo que devuelve la búsqueda pero `extracted` queda igual.
- El CSV respeta los filtros y abre bien con acentos (test que verifica BOM y separador).
- Un miembro no puede borrar (403); un admin sí, y el escaneo desaparece del listado.
