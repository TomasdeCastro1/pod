# T2.5 · Campos a leer, uso del mes y endpoints de administración

**Fase:** 2 · **Quién:** 🤖 Sonnet · **Depende de:** T2.2 (y T1.2) · **Tamaño:** M
**Rama:** `t2-5-campos-uso-admin`

## Objetivo

Endpoints para la configuración de campos con precio, la medición de uso mensual y el monitoreo interno.

## Contexto (leer)

- `docs/especificacion.md` §4.3 (pantalla «Campos a leer» y «Uso y precio»), §7, §11 (`/fields`, `/usage`, `/admin/*`), §12 completa.

## Qué hacer

1. `GET /companies/:id/fields` (miembro):
   ```json
   { "base_price": 40, "currency": "USD", "price_per_1000": 45,
     "groups": [ { "name": "Incluido", "fields": [ { "key", "label", "doc_types", "is_base": true, "enabled": true, "price": 0 } ] },
                 { "name": "Pago y referencias", "fields": [ ... ] } ] }
   ```
   Agrupado y ordenado por `sort_order`; solo campos `active`.
2. `PUT /companies/:id/fields { enabled: string[] }` (admin): solo claves opcionales activas (400 si viene una base o desconocida); reemplaza el conjunto en `company_fields` con `updated_by`; `audit_log` con el antes y después; devuelve lo mismo que el GET con el nuevo precio.
3. `GET /companies/:id/usage?month=AAAA-MM` (miembro; por defecto el mes actual en `America/Montevideo`):
   `{ month, images, price_per_1000_current, amount_usd, history: [ { month, images, amount_usd } x 6 ] }` con la regla de §12: solo `listo`/`revisar`, importe = Σ `price_per_1000_snapshot` / 1000, incluyendo escaneos con `deleted_at` (ya fueron procesados). Nada de costo IA.
4. Endpoints con `Authorization: Bearer <ADMIN_TOKEN>` (comparación en tiempo constante):
   - `GET /admin/usage?month=AAAA-MM`: por empresa → imágenes, costo IA real, % escalado, % a revisar, importe cobrado, margen (importe − costo).
   - `PUT /admin/field-catalog/:key { price_per_1000_usd?, instruction?, active?, label? }`.
   - `PUT /admin/price-settings { base_price_per_1000_usd }`.
   - `PUT /admin/model-prices/:model { input_per_mtok_usd, output_per_mtok_usd }` (útil para actualizar precios de modelos sin tocar la base a mano).

## Criterios de aceptación (tests)

- Activar `fecha_vencimiento`, `orden_compra` y `dev_plazo_retiro_dias` devuelve precio 45.
- Un miembro no puede guardar campos (403).
- Uso: con escaneos de distintos precios y estados en el mes, el importe y la cantidad cumplen §12 (errores no cuentan; borrados sí).
- `/admin/*` rechaza sin token o con token incorrecto.

## Fuera de alcance

Pantallas de la app (T5.2).
