# T1.3 · Utilidades de dominio en `shared`

**Fase:** 1 · **Quién:** 🤖 Sonnet · **Depende de:** T0.2 · **Tamaño:** S
**Rama:** `t1-3-utilidades`

## Objetivo

Funciones puras y bien testeadas que usan el backend y la app: RUT, números y fechas uruguayas, tipos de documento y CFE, y precio.

## Contexto (leer)

- `docs/especificacion.md` §6 (tipos CFE), §8.1 (reglas de números y fechas), §9.1 (algoritmo del RUT), §12 (fórmula de precio).

## Qué hacer (todo en `shared/src/`)

1. `rut.ts`
   - `isValidRut(rut: string): boolean` — 12 dígitos; pesos 4,3,2,9,8,7,6,5,4,3,2 sobre los primeros 11; dígito = 11 − (suma mod 11); 11 → 0; 10 → inválido.
   - `normalizeRut(input)`: quita puntos, guiones y espacios.
   - Tests con RUT válidos: `219419590017`, `216981070018`, `214214350013`, `210650500016`. Y casos inválidos: dígito cambiado, largo incorrecto, letras, caso que da 10.
2. `numbers.ts`
   - `parseUyNumber("1.416,32") → 1416.32`; acepta también `"1416.32"`, `"$ 1.727,91"`, negativos.
   - `parseRemitoQuantity("3,000") → 3` (en remitos la coma con tres ceros es separador decimal de cantidad: ver §8.1).
3. `dates.ts`
   - `ddmmyyyyToIso("24/09/2026") → "2026-09-24"`; validar fecha real; devolver `null` si no se puede.
4. `documents.ts`
   - Tipo `DocType = 'factura_emitida' | 'nota_credito_emitida' | 'devolucion_cliente' | 'otro' | 'no_reconocido'`.
   - Tipo `Conformidad = 'completa' | 'firma_sola' | 'dudosa' | 'sin_firma'`.
   - `CFE_TYPES`: mapa de código → nombre de la tabla de §6; `cfeName(code)` devuelve «otro CFE» si no se conoce.
   - `docFamily(docType)`: `factura` para factura/nota de crédito, `devolucion` para devolución, `null` para el resto.
   - `classifyFromQr(qrEmitterRut, companyRut, cfeCode)` según §5 y la decisión 13 del plan: emisor = empresa → `nota_credito_emitida` si CFE 102/112, si no `factura_emitida`; emisor distinto → `devolucion_cliente`.
5. `pricing.ts`
   - `pricePer1000(base: number, enabledOptionalPrices: number[])`.
   - `monthlyAmount(snapshots: number[])` = suma / 1000, redondeado a 2 decimales.
6. Exportar todo desde `shared/src/index.ts`.

## Criterios de aceptación

- Cobertura de tests de todos los casos anteriores; `npm test` verde.
- Sin dependencias externas en `shared` (debe correr igual en React Native).

## Fuera de alcance

Nada de base de datos ni red.
